# Star Wars Canon Lore

Небольшой лэндинг-шпаргалка по канону «Звёздных войн» на FastAPI.

## Возможности

- **Роли**
  - `неавторизованный` — только логин / регистрация
  - `reader` — просмотр главной страницы и своего профиля
  - `admin` — полный доступ + редактирование фракций

- **Данные**
  - `users.csv` — логин, SHA-256 пароль, путь к аватару, роль
  - `data.csv` — фракции (карусель на главной)
  - `logs.txt` — лог всех переходов и действий

- **Сессии** — cookie с таймаутом **5 минут**

## Запуск

```bash
cd star_wars_lore
pip install -r requirements.txt
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

Открыть: http://127.0.0.1:8000

### Учётные данные по умолчанию
- Логин: `admin`
- Пароль: `admin123`

## Страницы

| URL              | Описание                          | Доступ      |
|------------------|-----------------------------------|-------------|
| `/login`         | Вход                              | все         |
| `/register`      | Регистрация (роль reader)         | все         |
| `/home`          | Карусель фракций                  | reader+     |
| `/profile`       | Личный профиль                    | reader+     |
| `/admin/edit`    | Добавление / редактирование / удаление фракций | admin only |
| `/logout`        | Выход                             | авторизованные |

## Структура фракции (карточка)

- Символика (emoji / изображение)
- Название
- Титульное место
- Главные персонажи
- Сильные и слабые стороны
- Роль и место в произведении

## Логирование

Все запросы пишутся в `logs.txt` в формате:

```
[2026-11-25 10:15:03] user=admin | GET /home
[2026-11-25 10:15:10] user=admin | add_faction | id=11 name=...
```
